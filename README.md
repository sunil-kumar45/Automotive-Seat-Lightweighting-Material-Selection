# 🔬 Project Overview

This project focuses on reducing the weight of automotive seat structures through systematic material selection and evaluation of lightweight alternatives.

The study compares conventional materials with lightweight structural and cushioning materials based on weight, strength, cost, durability, manufacturability, corrosion resistance, recyclability, and overall performance.

The project investigates alternative materials for different seat components, including seat frames, cushioning, and upholstery, with the objective of achieving weight reduction while maintaining required functional and engineering performance.

# 🎯 Objectives

- Study the importance of seat lightweighting in automotive design.
- Evaluate lightweight materials for automotive seat structures.
- Compare mild steel with XPS steel, aluminum, magnesium, and CFRP.
- Investigate alternative materials for seat cushioning and upholstery.
- Perform systematic material selection using Pugh analysis.
- Estimate component-level weight reduction for selected materials.
- Consider cost, manufacturability, durability, and sustainability during material selection.

# 📊 Material Selection

A comparative evaluation was performed using engineering criteria such as:

- Weight
- Raw Material Cost
- Environmental Impact
- Ease of Manufacturing
- Durability
- Corrosion Resistance
- Strength
- Elastic Modulus
- Hardness

Pugh analysis was used to systematically compare candidate materials against the selected criteria.

# ⚙️ Pugh Analysis

Pugh analysis was applied for:

1. Seat-frame material selection
2. Cushioning-material selection
3. Upholstery-material selection

The analysis helped evaluate the trade-offs between weight, performance, cost, manufacturability, and other functional requirements.

# 📉 Weight Reduction Results

## Seat Frame

Using XPS steel for the investigated structural components:

- Base Frame Assembly: 5.782 kg → 4.0474 kg
- Back Frame Assembly: 4.236 kg → 2.965 kg
- Slider Assembly: 3.75 kg → 2.625 kg

Approximately **30% weight reduction** was achieved for the investigated seat-frame components.

## Cushioning Components

Using Ecofill fiber:

- Back Seat: 1.35 kg → 0.81 kg
- Seat Base: 1.36 kg → 0.816 kg
- Hand Rest: 0.738 kg → 0.44 kg

Approximately **40% weight reduction** was obtained for the investigated cushioning components.

## Upholstery Components

Using nylon for the selected cover components resulted in approximately **7.5% weight reduction**.
